# CadQuery-Project
CaDA \ LEGO compatible part designs created using CadQuery.

This little project combines my endearing interest in CAD Modelling and LEGO Builds.

Between CaDA, LEGO and Mattel, among others, there are a number of different basic part designs. COBI has 'inserts' and 'duos', 'CaDA' has more 'flip-flop-beams', and almost all basic plastic building block parts share common features with LEGO beams, bricks and plates. So, what if we can use something like CadQuery, a parametric, programmatic CAD Modelling system to create a unified collection of the basic LEGO compatible parts?

In part, that is what this project is about.
